# 지휘 산출물 모양 견본 (stub)

> 지휘가 새로 만드는 산출물은 **최종 결과 요약**(`orchestrator/result-summary.md`) 하나다. 아래는 그 모양 견본 — 값은 [input-sample.md](input-sample.md)의 결과 보고 견본(더미 5건 시나리오)을 그대로 취합한 것이며 실데이터 아님.
>
> 요약의 재료는 각 단계 결과 보고 JSON뿐이다 — 단계별 상태·건수는 `status`·`counts`를, 확인 필요 목록은 `flags`를 옮겨 적는다. 산출물 내용을 열어 요약하지 않는다.

## 최종 결과 요약 견본

```markdown
# 최종 결과 요약 (2026-02 결산)

## 1. 단계별 진행 현황

| 단계 | 상태 | 처리 건수 (전체/정상/확인필요) | 산출물 |
|---|---|---|---|
| 수집 | ok | 5 / 5 / 0 | collect/result.csv |
| 가공 | partial | 5 / 4 / 1 | refine/result.csv |
| 분류 검증 | partial | 5 / 2 / 3 | verify1/result.csv |
| 기간·금액 검증 | ok | 5 / 5 / 0 | verify2/result.csv |
| 통합 | partial | 5 / 2 / 3 | merge/result.xlsx, merge/result.pdf |

## 2. 확인 필요 목록

| 행 번호 | 단계 | 유형 | 사유 |
|---|---|---|---|
| 5 | 가공 | 확인 필요 | 가맹점 식별·카테고리 분류 불가 (무신사) |
| 3 | 분류 검증 | 반려 | 카테고리 "식비"는 체계에 없음 — "식대"로 추정 |
| 4 | 분류 검증 | 반려 | 카테고리 "카페"는 체계에 없음 — "식대"로 추정 |
| 5 | 분류 검증 | 반려 | 카테고리가 비어 있어 판정 불가 |
| 3, 4, 5 | 통합 | 미완 | 반려 미해결 건 — 장부에 "확인 필요" 표시로 실림 |

## 3. 산출물 위치

- 엑셀 회계장부: `merge/result.xlsx`
- PDF 결산 리포트: `merge/result.pdf`

## 4. 메모

전 단계 `counts.total`(5건) 대조 결과 유실 없음. 실행 기록: `logs/run_20260301_090000/` (진행 로그 + 단계별 보고 아카이브)
```

## 작성 규칙

- 실패·중단이 있어도 이 요약은 **반드시 작성**한다 — 진행된 단계까지 1장에 적고, 실패 단계의 `message`를 4장 메모에 옮겨 적는다
- 확인 필요 목록(2장)은 각 단계 결과 보고의 `flags`를 단계 표시와 함께 그대로 취합한다 (재판정하지 않는다)
- 산출물 위치(3장)는 통합 결과 보고의 `output` 경로를 그대로 안내한다
