# 수집 받는 재료 견본 (input-sample)

> collect가 받는 두 원천 중, 카드사 Excel/CSV는 `sample_data/hana_card/`에 더미로 준비돼 있다. 영수증 이미지·결제 문자 캡처(OCR 대상)는 아직 견본이 없다 — 이미지 파일이라 텍스트 견본으로 대체하기 어렵고, 필요해지면 별도로 준비한다.
>
> **실제 처리 대상은 `sample_data/hana_card/`의 CSV 파일 전체**다. 이 문서의 표·2행 예시는 컬럼이 어떻게 생겼는지 보여주는 견본일 뿐, 그 자체가 처리 재료는 아니다 — 실행할 때는 이 문서가 아니라 `sample_data/hana_card/` 원본을 읽는다.
>
> 아래는 하나카드(개인카드) 서식 **한 가지 예시**다. 카드사마다, 그리고 법인카드냐 개인카드냐에 따라 컬럼 구성이 달라질 수 있다 — 새 카드사·법인카드 샘플이 추가되면 이 문서에 서식별로 나란히 추가한다. [`collect.md`](../.claude/agents/collect.md) "하는 단계 1"의 정규화 규칙이 서식마다 다른 컬럼을 표준 필드로 흡수하는 지점이다.

## 1. 카드사 Excel/CSV — 하나카드 이용내역서 (개인카드 서식 예시)

`sample_data/hana_card/2026-02_하나카드_이용내역서.csv`에서 그대로 가져온 값:

| 컬럼 | 설명 | 예시 |
|---|---|---|
| 이용일자 | 결제일 (할부는 최초 구매일 그대로 유지) | 2026-02-02 |
| 이용가맹점 | 가맹점명 (PG사 표기 그대로 — 정규화는 가공 단계 몫) | 쿠팡 |
| 이용금액 | 거래 총액 (할부는 매달 같은 값 반복) | 67,302 |
| 할부기간 | `일시불` 또는 `N개월` | 일시불 |
| 회차 | 할부일 때만 `N/전체` (일시불은 `-`) | - |
| 원금 | 이번 청구에 포함된 원금 | 67,302 |
| 수수료 | 이번 청구에 포함된 할부 수수료 (일시불은 0) | 0 |
| 이용혜택 | 적용된 혜택명, 없으면 `없음` | 포인트 적립 |
| 혜택금액 | 혜택 금액, 없으면 0 | 1,346 |
| 결제후잔액 | 할부 잔여 원금 (일시불은 0) | 0 |
| 포인트 | 적립 포인트 | 337 |

원본 예시 2행:

```csv
이용일자,이용가맹점,이용금액,할부기간,회차,원금,수수료,이용혜택,혜택금액,결제후잔액,포인트
2026-02-02,쿠팡,67302,일시불,-,67302,0,포인트 적립,1346,0,337
2026-02-03,CGV,15674,일시불,-,15674,0,없음,0,0,78
```

할부 거래는 [stub.md](stub.md)의 "할부 거래" 예시를 참고 (하이마트 냉장고, 2026-02-10 구매 · 6개월 할부).

## 2. 영수증 이미지·결제 문자 캡처 (OCR 대상)

- 형식: Google Drive·Google Photos에 업로드된 이미지 파일 (사진·스크린샷)
- 견본: 없음 — 이미지라 텍스트 파일로 대체할 수 없다. OCR 처리 확인이 필요해지면 실제 이미지 견본을 별도로 준비해야 한다
- 추출 대상 정보: 거래일 · 금액 · 결제처 · 결제수단 (`collect.md` "하는 단계" 참고)
