# ledger-flow

**월말결산 에이전트 — 다중 카드 통합 AI 자동 결산 시스템**

개인·법인 명의가 섞인 여러 카드의 결제 내역(카드사 엑셀·영수증 사진·결제 문자)을 모아,
멀티 에이전트 파이프라인이 월 결산 산출물(엑셀 회계장부 + PDF 결산 리포트)을 자동 생성합니다.

수집 → 가공 → 검증 1·2(병렬) → 통합, 오케스트레이터가 흐름을 지휘합니다.
