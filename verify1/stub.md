# 분류 검증 산출물 모양 견본 (stub)

> verify1이 내놓는 것은 **판정이 붙은 거래 표**(CSV)다. [input-sample.md](input-sample.md)의 견본을 그대로 판정한 결과이며, 값은 `sample_data/hana_card/`의 더미 데이터 기반 — 실데이터 아님.
>
> 받은 행을 지우거나 순서를 바꾸지 않는다. 뒤에 판정 열 두 개만 덧붙인다.
>
> 거래 표 스키마 컬럼은 한글([interface-spec.md](../docs/interface-spec.md) 기준), 이 단계가 더하는 판정 필드는 영문으로 둔다 — 수집의 `collect_status`와 같은 규칙이다.

## 더하는 컬럼

| 컬럼 | 값 | 설명 |
|---|---|---|
| `verify1_result` | `통과` / `반려` | 분류 관점 판정 |
| `verify1_reason` | 한 줄 문자열 | 반려 사유. 통과면 비워 둔다 |

## 판정 결과 예시

입력 컬럼은 그대로 두고(지면상 일부만 표시) 오른쪽 두 열이 이 칸의 산출물이다.

| transaction_id | 날짜 | 결제처 | 카테고리 | `verify1_result` | `verify1_reason` |
|---|---|---|---|---|---|
| `tx_260202_01` | 2026-02-02 | 쿠팡 | 기타물품 | 통과 | |
| `tx_260203_01` | 2026-02-03 | CGV | 기타 | 통과 | |
| `tx_260224_01` | 2026-02-24 | 배달의민족 | 식비 | 반려 | 카테고리 "식비"는 체계에 없음 — "식대"로 추정 |
| `tx_260226_01` | 2026-02-26 | 스타벅스 강남점 | 카페 | 반려 | 카테고리 "카페"는 체계에 없음 — "식대"로 추정 (커피·디저트는 식대 포함 범위) |
| `tx_260207_01` | 2026-02-07 | 무신사 | | 반려 | 카테고리가 비어 있어 판정 불가 (가공에서 "확인 필요" 처리된 건) |

`tx_260203_01`은 명칭이 체계에 있으므로 통과다. 영화관 지출에 `기타`가 어울리는지는 이 칸이 정하지 않는다 — 어긋나 보이면 반려 대신 `verify1_reason`에 의견만 남긴다.

## 결과 보고

산출물과 함께 지휘에게 돌려주는 요약 JSON. 형식은 [인터페이스 정의서](../docs/interface-spec.md)의 "단계 결과 보고"를 따른다. 위 5건 기준:

```json
{
  "stage": "verify1",
  "status": "partial",
  "output": "verify1/result.csv",
  "counts": { "total": 5, "ok": 2, "flagged": 3 },
  "flags": [
    { "row": 3, "type": "반려", "reason": "카테고리 \"식비\"는 체계에 없음 — \"식대\"로 추정" },
    { "row": 4, "type": "반려", "reason": "카테고리 \"카페\"는 체계에 없음 — \"식대\"로 추정" },
    { "row": 5, "type": "반려", "reason": "카테고리가 비어 있어 판정 불가" }
  ],
  "message": ""
}
```

전 건 통과면 `status`는 `ok`, `flagged`는 0이 된다.

## 확인 대상이 없을 때

데이터 행이 0건이면 빈 파일을 내놓지 않는다. 결과 파일에 `"확인 대상 없음"`을 남기고 보고의 `status`는 `empty`로 한다.

| transaction_id | 날짜 | 결제처 | 카테고리 | `verify1_result` | `verify1_reason` |
|---|---|---|---|---|---|
| | | | | 확인 대상 없음 | 검증할 항목이 없음 |

```json
{
  "stage": "verify1",
  "status": "empty",
  "output": "verify1/result.csv",
  "counts": { "total": 0, "ok": 0, "flagged": 0 },
  "flags": [],
  "message": "확인 대상 없음"
}
```
