# 기간·금액 검증 (verify2) — 이 칸의 약속

> 담당: 이지은 · 기간·금액 관점 검증 · 상태: 초안
> 계약의 정본은 [인터페이스 정의서](../docs/interface-spec.md), 단계 문서(설계+실행 지시의 단일 정본)는 [.claude/agents/verify2.md](../.claude/agents/verify2.md).

## 받는 것 / 내놓는 것

- **받는 것**: 가공된 거래 표 (`refine/result.csv`, 분류 검증과 동일 입력) — CSV, 거래 표 스키마 v1
- **내놓는 것**: 행별 통과/반려/대상외 결과 + 이유 한 줄 — CSV (`verify2/result.csv`). `대상외`(대상 월 아님)는 지휘가 확인 없이 결산에서 뺀다
- **실행 파라미터**: 대상 월(`YYYY-MM`) — 지휘가 호출 시 전달
- **못 할 때**: 확인할 항목이 없으면 `"확인 대상 없음"`으로 표시

## 이 칸의 파일

| 파일 | 무엇 |
|---|---|
| `README.md` | 이 문서 — 칸의 약속 |
| `input-sample.md` | 받는 재료 견본 (가짜 데이터) |
| `stub.md` | 산출물 모양 견본 (가짜 데이터) |
| `result.*` | 진짜 산출물 — 실행하면 생김. **커밋하지 않는다** |

칸 폴더를 옮기지 않고, 기존 파일을 지우지 않는다. 새 산출물은 견본 옆에 만든다.

## 지켜야 할 것

- **실데이터를 커밋하지 않는다.** 견본은 [sample_data/](../sample_data/)의 가짜 데이터로만 만든다 (개인 금융정보)
- **문서 먼저, 구현 나중.** 동작을 바꾸려면 [단계 문서](../.claude/agents/verify2.md)를 먼저 고친다. 단계 간 약속이 걸리면 [인터페이스 정의서](../docs/interface-spec.md)를 담당자 합의로 고친다

## 테스트 방법

`sample_data/`의 더미 데이터로만 테스트한다 (실데이터 사용 금지 — AGENTS.md §8). 판단 기준 세 가지(대상 월·금액 단일 기입·해외결제 환산)를 각각 걸리게/안 걸리게 설계한 샘플 가공 거래 표를 두고, 기대 결과(행별 통과/반려 + 사유)와 대조한다. 해외결제 케이스(`원거래통화`·`원거래금액`이 채워진 행)도 샘플에 포함한다.
