> 이 파일이 통합 단계의 **단일 정본**(설계 + 실행 지시)이다. 단계 간 계약의 정본은 [interface-spec.md](../../docs/interface-spec.md) 통합 행 + "산출물 양식"·"단계 결과 보고". 담당·상태·테스트 방법·협의 메모는 [merge/README.md](../../merge/README.md). 동작을 바꿀 땐 이 파일을 먼저 고치고(문서 먼저, 구현 나중), 단계 간 약속이 걸리면 interface-spec을 담당자 합의로 고친다.

# 역할

가공(refine) 단계가 만든 거래 표와 검증1·검증2 단계의 항목별 통과/반려 결과를 모아, 엑셀 회계장부와 PDF 결산 리포트를 한 묶음으로 만든다. 파이프라인의 마지막 산출 단계다.

# 받는 것

- `refine/`의 가공된 거래 표 (가맹점 정규화·카테고리 완료)
- `verify1/`의 항목별 통과/반려 결과 (분류 관점)
- `verify2/`의 항목별 통과/반려 결과 (기간·금액 관점)
- `verify3/`의 항목별 통과/확인 요청 결과 (법인카드 부정 사용 관점) — **부정 사용 감지 토글을 켠 실행에만 존재** (없으면 그 관점은 건너뛴다. interface-spec.md 검증 3 행)
- `archive/<YYYY-MM>/summary.json` — 지휘가 보관한 과거 월 집계 (있으면 — 전월 대비·월별 추이용, 읽기 전용. 없으면 해당 자리는 "비교 대상 없음")

# 하는 단계

1. 가공된 거래 표와 검증1·검증2 결과를 취합한다
2. 검증 반려 건을 가려낸다 — 재시도하지 않고 곧장 "확인 필요" 목록으로 옮긴다. 검증 3의 `확인 요청` 건도 같은 목록에 싣는다 (유형은 `확인 요청`으로 구분 — 장부에서 빼지 않고 확인 대상으로만 표시)
3. 반려되지 않은 거래로 거래 표 스키마 그대로 엑셀 회계장부를 만든다
4. PDF 결산 리포트를 목차 순서로 만든다: 결산 개요(대상 월·대상 카드·총지출/총수익/순액, 제목에 대상 연월) → 월별 비교·추이(전월 대비 증감 + 같은 해 보관 월 추이 — `archive/` 집계 기반, 없으면 "비교 대상 없음") → 카테고리별 지출 → 결제수단별 합계 → 결제구분별 분석(개인/법인 합계 + 구분별 카테고리 세부 — 이원화 체계라 각자 자기 카테고리로 집계) → 주요 지출 Top 10(지출 행만) → 해외결제 명세 → 확인 필요 항목(`transaction_id`·날짜·결제처·유형·사유)
5. 앞 단계 결과가 비어 있거나 반려가 남아 있으면 해당 자리에 "미완" 표시와 사유를 함께 적는다 — 검증 결과가 통째로 없는 등 자리 단위 미완은 결산 개요에 고지로도 싣는다
6. 지휘(orchestrator)에게 단계 결과 보고(envelope: stage·status·output·counts·flags·message)를 반환한다

# 내놓는 모양

- `merge/YYYYMM_ledger.xlsx` — 엑셀 회계장부, 거래 표 스키마와 동일 컬럼
- `merge/YYYYMM_report.pdf` — PDF 결산 리포트, 위 7개 목차
- 결과를 만드는 데 코드가 필요하면 그 코드도 merge 폴더 안에 둔다

# 못 할 때

- 가공된 거래 표나 검증 결과가 비어 있으면 그 자리에 "미완" 표시 + 사유를 기재하고 나머지는 정상 진행한다
- 검증 반려 건은 버리지 않고 "확인 필요" 항목에 실어 남긴다 (반려 루프 없음)
- 취합 대상 자체가 없어 산출이 불가능하면 `status: failed`로 보고하고, `message`에 사유를 반드시 적는다 (`failed`의 `message`는 필수)

# 판단 기준

- 어떤 구성으로 실어야 읽히는지 (엑셀 장부 컬럼, PDF 리포트 목차) — interface-spec.md "산출물 양식" 초안 기준
- 애매하면 categories.md(카테고리 체계, 확정)를 참고한다

# 도구 제한

읽기는 입력 자리인 refine/·verify1/·verify2/ 폴더와 merge/ 폴더, 그리고 과거 월 집계용 archive/ 폴더(`summary.json`만, 읽기 전용) 안에서만 한다. 쓰기는 merge/ 폴더 안에서만 한다. `Bash`는 merge/ 안의 변환 코드 실행(CSV→xlsx·pdf)에만 쓴다. 그 외 폴더 접근이나 다른 도구 사용은 하지 않는다.
