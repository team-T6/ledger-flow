# 렛저 Ledger Flow — 디자인 가이드 · 브랜딩

> 브랜드 정의와 화면·산출물 스타일 기준의 단일 정본.
> 여기 적힌 값은 구현에서 추출한 현행 기준이다 — 값을 바꾸려면 이 문서를 먼저 고치고 구현에 반영한다(spec-first).
> 구현 정본 위치: 웹 `web/index.html` 상단 `:root` 테마 토큰 · PDF `merge/build_result.py` 색 상수.

## 1. 브랜드

### 1.1 서비스명·표기 (확정)

- 정식 표기: **렛저 Ledger Flow** (한글 호칭 "렛저", 영문 "Ledger Flow" — 병기 시 한글 먼저)
- 부제(태그라인): **월말결산 비서** (확정) — 사용자 대면 화면·메타 설명의 정본 표기. 내부·기술 문서에서 파이프라인 구조를 가리킬 때의 "에이전트"는 기술 용어로 병용한다 (사용자 대면 카피에는 쓰지 않는다)
- 저장소·코드 식별자: `ledger-flow` (소문자 케밥)

### 1.2 컨셉 (확정)

**"회계장부를 서재에 넣고 보관한다"** — 월말결산의 결과물을 종이 장부처럼 만들어 서고(書庫)에 꽂아 두는 은유.

이중 은유 구조 (확정): **비서 = 행위자**(장부를 대신 써 주는 사람) · **서재 = 공간**(그 장부가 꽂히는 곳). "비서가 결산을 마친 장부를 서재에 꽂아 둔다"로 이어지는 한 세계관이며, 부제의 "비서"는 전달력을 위해 은유의 시대감보다 우선한 선택이다.

- 화면 어휘도 은유를 따른다: 결산이 끝난 달의 목록은 **"결산 서고"**, 완료 동작은 **"보관"**, 완료된 달은 "장부가 꽂혀 있다"고 말한다
- 시각 테마 이름: **장부 에디토리얼** — 종이 질감의 아이보리 배경 + 짙은 잉크 + 제본 녹색. 화려한 앱이 아니라 "잘 만든 인쇄물"처럼 보이는 것이 목표
- 다크 모드 없음 (의도된 단일 테마 — 종이 장부 은유상 배경은 항상 종이색)

### 1.3 톤앤매너 (확정 — 현행 카피 기준)

- 존댓말 해요체 아닌 **합쇼체 중심** ("~드립니다", "~됩니다"), 담백하고 신뢰감 있게
- 렛저를 1인칭 주어로 세워 말한다: "렛저가 대신합니다", "렛저가 결산하고 있습니다"
- 과장·이모지·느낌표 남용 없음
- 카피는 **한국어만** 쓴다 (확정) — 영문 태그라인·메타 설명을 만들지 않는다 (서비스명 "Ledger Flow" 병기는 예외)

### 1.4 로고 (확정)

- `web/favicon.svg`의 마크(종이색 배경 + 제본 녹색 인장풍 글자)가 **정식 로고를 겸한다** — 별도 로고타입을 만들지 않는다
- 문자 병기가 필요한 곳은 마크 + 브랜드명 텍스트("렛저 Ledger Flow", §3.1 디스플레이 서체) 조합으로 운용한다

## 2. 색상 (확정)

팔레트는 웹·PDF가 공유한다. 이름은 웹 CSS 변수 기준.

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `--bg` | `#FAF7F2` | 페이지 배경 (종이색). PDF 페이지 배경·accent 위 글자색으로도 사용 |
| `--ink` | `#1C1917` | 본문 글자 (잉크색) |
| `--muted` | `#7A7263` | 보조 글자·설명·라벨 |
| `--line` | `#E6DFD2` | 괘선·테두리·구분선 |
| `--soft` | `#EFE9DD` | 옅은 채움 (배지·고스트 버튼 배경) |
| `--card` | `#F5F1E8` | 카드·패널 배경 |
| `--accent` | `#1E5B45` | **메인 테마색 (제본 녹색)** — 버튼·강조·섹션 띠·표 헤더·긍정 지표 |
| `--accent-soft` | `#C9D8CC` | accent의 옅은 톤 (미니 차트 막대 등) |
| `--red` | `#A63A2E` | 부정·경고 — 반려·확인 필요·지출 증가. 이 용도 외 사용 금지 |

사용 규칙:

- 구조적 요소(제목·헤더·버튼)는 accent 한 가지로 통일한다. 단일 시리즈 차트도 accent만 쓴다
- 다중 시리즈(파이 등)는 accent 녹색을 밝기로 벌린 계열을 먼저 쓰고, 조각이 많을 때만 보조 톤으로 이어간다 (정본: `merge/build_result.py`의 `SERIES_COLORS`)
- red는 "나쁜 소식" 전용이다. 증감 표시에서 지출 증가 = red, 감소 = accent

## 3. 타이포그래피

### 3.1 웹 (확정)

| 역할 | 글씨체 | 굵기 |
| --- | --- | --- |
| 디스플레이 (h1·h2·브랜드명) | **Noto Serif KR** (serif) | 900 (Black) |

- 제목은 세리프 굵은 글씨 — "인쇄된 장부 표제" 인상의 핵심. 본문에 세리프를 쓰지 않는다
- 금액·표의 숫자 열은 반드시 mono + tabular-nums (자릿수 정렬)
- 로딩: Google Fonts (`web/index.html:11`)

### 3.2 PDF 리포트 (확정)

- 전체 **NanumGothic-Regular** 단일 폰트 유지 (`merge/fonts/`, OFL 라이선스 전문 동봉)
- 웹의 3서체 체계와 의도적으로 다르다. 선정 기준은 라이선스 > 가독성 — 후보였던 Noto 계열도 같은 OFL이라 라이선스 우위가 없고, NanumGothic은 PDF 생성기(reportlab)가 요구하는 TrueType 형식이라 임베드가 확실하다는 점에서 유지

## 4. 컴포넌트·레이아웃 규칙 (확정 — 웹 기준)

- 모서리: `--radius: 4px` — 둥근 맛을 거의 주지 않는다 (인쇄물 인상). 모달만 6px
- 카드: `--card` 배경 + `--line` 1px 테두리. 그림자 대신 괘선으로 구획한다
- 버튼: 기본 = accent 채움 / ghost = `--soft` 채움 / quiet = 투명. 포커스는 accent 2px 아웃라인
- 배지·아이콘 칩: accent 채움 + 종이색 글자
- 진행 중 상태(현재 결산월 카드): accent **점선 2px** 테두리로 구분
- 확인 표(수집·가공·검증 확인 지점·재결산 공용): 열 순서는 `반영 체크 + 제외(휴지통)` · `거래` · `결제구분` · `날짜` · `금액` · `결제처` · `카테고리` · `구매항목` · `비고` 로 **전 지점 동일**하게 세운다 (단계마다 열리는 필드 수는 달라도 순서는 이 정본을 따른다). `결제구분`은 카테고리 선택지를 가르는 전제라 값 필드 맨 앞. 결산 제외는 별도 열이 아니라 반영 체크박스 옆 휴지통 아이콘 토글 — 켜면 그 행의 입력을 잠그고 흐리게 표시한다
- 본문 폭: 대시보드 기본 720px, 표가 있는 진행·결과 화면 1400px, 서고에서 펼친 보관월 상세는 '한 면'으로 읽히도록 1240px (양옆 여백 유지)
