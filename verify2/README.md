> 설계서(정본): [docs/agents/verify2.md](../docs/agents/verify2.md) · 지시서: [.claude/agents/verify2.md](../.claude/agents/verify2.md) · 계약: [인터페이스 정의서](../docs/interface-spec.md)

## 받는 것 / 내놓는 것

- **받는 것**: 가공 단계 결과 (거래 내역)
- **내놓는 것**: 항목별 통과/반려 결과
- **모양**: 항목마다 통과 또는 반려와 이유 한 줄이 있는 표
- **못 할 때**: 확인할 항목이 없으면 `"확인 대상 없음"`으로 표시

## 이 칸의 파일

| 파일 | 무엇 |
|---|---|
| `README.md` | 이 문서 — 칸의 약속 |
| `stub.md` | 산출물 모양 견본 (가짜 데이터) |
| `result.*` | 진짜 산출물 — 실행하면 생김. **커밋하지 않는다** |

칸 폴더를 옮기지 않고, 기존 파일을 지우지 않는다. 새 산출물은 견본 옆에 만든다.

## 지켜야 할 것

- **실데이터를 커밋하지 않는다.** 견본은 [sample_data/](../sample_data/)의 가짜 데이터로만 만든다 (개인 금융정보)
- **명세 먼저, 구현 나중.** 동작을 바꾸려면 [설계서](../docs/agents/verify2.md)를 먼저 고친다. 단계 간 약속이 걸리면 [인터페이스 정의서](../docs/interface-spec.md)를 담당자 합의로 고친다
