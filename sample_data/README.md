# sample_data — 더미데이터 케이스 목록

> 파이프라인 개선용 더미데이터. **일부러 지저분하게** 만들었다 — 서식·인코딩·데이터 품질 함정이 곳곳에 심겨 있고, 파이프라인이 이 함정들을 어떻게 처리하는지 보는 것이 목적이다.
> 전부 생성한 가짜 값이며 실데이터가 아니다. 컬럼 서식 설명은 [collect/input-sample.md](../collect/input-sample.md) 참조 — 이 문서는 **심어둔 함정과 기대 동작**만 다룬다.
>
> 시연 대상 월: **2026-07**

## 1. 카드사 CSV

### hana_card/ — 개인카드 (기준 데이터, 깨끗함)

- 2026-02 ~ 07 월별 6개 파일. 함정 없음 — 정상 경로 확인용 베이스라인.
- 할부 케이스 1건 포함 (하이마트 냉장고, 2026-02 구매 6개월 할부 → 07월 파일에 6/6 회차).

### shinhan_corp/ — 법인카드 (서식 다름 + 의미상 함정)

UTF-8, 서식 자체는 규칙적이지만 데이터에 검증을 자극하는 케이스가 있다:

| 행 | 함정 | 기대 동작 |
|---|---|---|
| 06-30 23:58 쿠팡 | 대상 월 이전 거래 | 검증 2 "대상 월" 기준 반려 |
| 08-01 00:12 카카오T | 대상 월 이후 거래 | 상동 |
| 07-09 APPLE.COM (USD 39.99 → 55,890원) | 환산 환율 약 1,398원/달러 — 정상 범위 | 검증 2 환산 확인 통과 |
| 07-11 AWS EMEA (USD 89.50 → 18,240원) | 환산 환율 약 204원/달러 — **명백한 오류** | 검증 2 환산 기준 반려 |
| 07-14 한우마을 2행 (같은 승인번호 30789602, 취소여부 N/Y) | 승인 + 취소 쌍 | 상계 처리? 수익 기입? — 처리 방침 미정, 어떻게 나오는지 관찰 |
| 07-18 GS25 학동역점 8,700원 | `receipts/receipt_gs25_2026-07-18.png` 영수증과 **같은 거래** (승인번호 30812456 일치) | 교차 원천 중복 — 통합 시 이중 기입되면 안 됨 |
| 해외결제 행의 공급가액·부가세 공란 | 결측 | 정규화가 빈 값을 어떻게 다루는지 |

### kb_card/ — 개인카드 (파일 서식 함정)

**cp949(EUC-KR) 인코딩** — UTF-8로 읽으면 전체 깨짐. 그 외:

| 함정 | 위치 |
|---|---|
| 표 위 머리말 4줄 (제목·회원명·조회기간·빈 줄) | 파일 상단 |
| 표 아래 `합계` 행 + `※` 안내문 행 | 파일 하단 — 거래로 오인하면 안 됨 |
| 날짜가 점 표기 `2026.07.03` | 전 행 |
| 금액이 따옴표+쉼표 `"1,890,000"` | 전 행 |
| 해외결제가 가맹점명에 섞임 `AMAZON.COM 29.99 USD` (통화 컬럼 없음) | 07.12 행 |
| 음수 금액 `-32,000` (하이마트 환불) | 07.28 행 — 수익? 지출 차감? |
| 할부 표기가 `06개월` (하나카드는 `6개월`) | 07.16 행 |

### lotte_card/ — 명의 불명 (데이터 품질 함정)

UTF-8이지만 데이터가 지저분하다:

| 함정 | 위치 |
|---|---|
| 완전 중복 행 | 07-04 메가커피 2행 |
| 날짜 형식 3종 혼재: `2026-07-04` / `07/09/2026` / `2026년 7월 11일` | 각 행 |
| 금액 표기 혼재: `"4,500원"` / `8900` / 공란 | 각 행 |
| 따옴표 없는 쉼표 포함 가맹점명 `김밥천국, 서현점` → **컬럼 수 어긋남** | 07-10 행 |
| 필드 앞뒤 공백 `  네이버플러스 멤버십  ` | 07-13 행 |
| 구분이 `수익`인 행 (캐시백) | 07-15 행 |
| 금액 공란 (이케아) | 07-17 행 — 버릴지 오류 표시로 남길지 |
| 음수 금액 + 구분 공란 (쿠팡 반품환불) | 07-19 행 |
| 구분이 `지출/수익` 둘 다 | 07-22 행 — 검증 2 "단일 기입" 반려 대상 |
| 미래 날짜 `2026-09-01` | 마지막 행 |
| 결제자(개인/법인) 정보가 파일 어디에도 없음 | 파일 전체 |

## 3. 재생성

- CSV는 손으로 수정해도 된다. 이미지는 스크립트로 생성했다 — 재생성이 필요하면 요청 시 스크립트를 다시 준비한다 (Pillow 사용, 세션 스크래치패드에서 생성).
