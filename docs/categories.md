# 카테고리 체계

> 최종 업데이트: 2026-08-31 13:12
> 상태: 확정 (확정 로그는 [인터페이스 정의서](interface-spec.md) "다음 단계"). 회사 회계 계정과목을 개인·법인 카드 통합 결산에 맞게 번안한 체계. 가공(분류)·분류 검증(적합성 확인)이 공용으로 쓴다.
> 지출 표는 개인/법인 두 표로 분리 관리한다 (2026-08-31 확정 — 설정 화면의 독립 편집에 맞춤). `결제구분`이 `개인결제`면 [지출 — 개인카드], `법인결제`면 [지출 — 법인카드] 표를 쓴다. 판정·분류는 **실행 시점의 이 파일 기준**이다 — 웹 설정 화면(분류 기준 메뉴)에서 편집할 수 있다.

## 운영 규칙

- 가공 단계에서 분류가 애매한 건은 임의 배정하지 않고 "확인 필요"로 표시한다 (인터페이스 정의서 "못 할 때" 규칙).
- 경조사 구분: 거래처·외부 인사는 접대·경조사(접대비), **임직원 경조사는 회계상 복리후생비**라 구분이 필요하면 비고에 표기한다.
- 카테고리 추가·삭제·이름 변경은 이 문서를 먼저 고치고(spec-first), 가공·분류 검증 에이전트가 따른다.
