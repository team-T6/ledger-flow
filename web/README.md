# web — 쇼케이스 + 로컬 실행 페이지 (렛저 — Ledger Flow · 월말결산 비서)

랜딩 + 결산 플로우(초대코드 → 결산 서고 → 자료 넣기 → 결산 진행 → 결과)를 담은
정적 단일 페이지(`index.html`). 테마는 장부 에디토리얼 한 가지로 고정되어 있다.

## 화면 구성 (확정)

- **랜딩**은 스크롤 내러티브(화면 단위 스냅)를 유지한다.
- **결산 화면(#app)은 스크롤 없이 화면 전환으로 동작한다** — 진입하면 "결산 서고"
  (연도 전환 ‹ › + 12개월 그리드) 하나만 보이고, 달을 누르면 대시보드로 들어간다:
  - 왼쪽 사이드바: "‹ 결산 서고" 복귀 버튼 + 연도 전환 + 12개월 목록 (월 전환 한 클릭)
  - 오른쪽 본문: 선택한 달의 상태에 따라 보관본 상세 / 자료 넣기 → 결산 진행 → 결과로 바뀐다
- **결산 단계 스텝**: 대시보드 상단에 "자료 넣기 → 결산 진행 → 결산 결과" 스텝이 떠 있고,
  도달한 스텝은 탭처럼 눌러 오간다. 각 화면 하단에 이전/다음 버튼도 있다.
- **결과 화면**은 개요 3칸(총지출·총수익·순액)을 상시 두고, 나머지는 탭으로 접는다:
  카테고리 · 전월 비교 · 결제구분 · 주요 지출 · 비고 · 자세히(PDF 미리보기·요약 전문)
- **자동 저장**: 결산이 끝나면 결과가 자동으로 결산 서고에 저장된다 — 결과 화면에
  "결산 서고에 저장되었습니다" 안내와 "다시 결산하기"가 함께 뜬다
- **전월 비교**: 총지출 칸에 전월 대비 증감이 붙고, "전월 비교" 탭에서 최근 월 추이와
  거래·확인 필요 건수의 전월 대비를 본다. 1월은 지난해 12월 보관본과 이어서 비교한다.
- **다시 결산하기**: 결과 화면과 보관월 상세 양쪽에 있다 — 그 달의 자료 넣기로 돌아간다.

같은 파일이 **여는 방법에 따라 두 모드로 동작**한다:

| 모드 | 언제 | 동작 |
|---|---|---|
| 데모 (기본값) | GitHub Pages·`file://`·일반 정적 서버 | 하드코딩 샘플 연출 — 실제 실행·업로드·다운로드 없음 |
| 실제 (로컬) | `python3 orchestrator/server.py`로 서빙된 `http://localhost:8788` | 업로드한 파일로 실제 결산 파이프라인(Claude 에이전트 호출) 실행 |

모드 감지는 페이지 로드 시 `GET /health` 프로브 하나 — 실패하면 무조건 데모라서,
서버 없는 환경에서 데모가 깨질 일이 없다.

## 실제 모드로 쓰기 (로컬)

1. 리포 루트 `.env`에 `INVITE_CODE=...`(초대코드, 자유 값)를 둔다. 인증은 둘 중 하나 — `.env`에 `ANTHROPIC_API_KEY=...`를 넣거나, **claude CLI에 로그인**되어 있으면 키 없이도 CLI 세션으로 자동 실행된다
2. `python3 orchestrator/server.py` 실행 → http://localhost:8788 접속
3. 초대코드 입력(서버가 `.env`와 대조) → 결산 서고에서 월 선택 → 카드사 CSV·영수증 이미지 업로드 → 결산 시작
4. 진행 로그가 실시간으로 흐르고, 끝나면 결과 화면에서 PDF·엑셀을 받는다
5. 진행 중 확인 필요·반려 건이 생기면 **중간 확인 패널**이 떠서 파이프라인이 일시정지된다 — 행별로 값을 고쳐 "확인한 내용 반영하고 계속"을 누르면 사용자 확인으로 반영되고, "모두 그대로 두고 계속"이나 10분 무응답이면 기존처럼 확인 필요 목록으로 남는다 (수집·가공 직후, 통합 직전 — 데모 모드에는 없음)

업로드 파일은 `uploads/inbox/`에 놓인다 (gitignore 차단 — 커밋되지 않는다).
개발자용 지휘 대시보드는 같은 서버의 `/screen.html`에 그대로 있다.

### 결산 서고 (실제 모드)

결산이 정상 종료되면 파이프라인이 (웹·CLI 어느 경로로 실행했든) 최종 산출물을 `archive/<YYYY-MM>/`에 보관한다
(`result.pdf` · `result.xlsx` · `result-summary.md` + 집계 수치 `summary.json` — gitignore 차단).
결산 서고가 월 선택 화면을 겸한다: 보관된 달을 클릭하면 개요·전월 대비·지출 추이와 함께
저장된 리포트·장부를 바로 열거나 받을 수 있고, "다시 결산하기"로 재실행할 수도 있다.
연도는 보관된 데이터에서 자동으로 늘어나고, 지난해까지는 보관 여부와 무관하게 이동할 수 있다 (‹ › 전환).
"새로 결산하기"는 **오늘이 포함된 달까지만** 열린다 — 미래 달은 "자료 없음"으로 잠긴다.

자동 저장과의 관계: 파이프라인은 (웹·CLI 공통 규칙대로) 종료 직전에 보관본을 만들어 두고,
웹은 결산이 끝나면 그 보관본을 서고 목록에 바로 반영한다 (자동 저장).

### 결산 진행률 (실제 모드)

가공·검증 단계는 API 스트리밍 응답의 처리 행수를 세어 **처리 건수 기반 진행률**
(예: 가공 26/42건)을 실시간 표시한다. claude CLI 폴백으로 실행될 때는 건수 진행률이
없어 경과 시간과 부정형(움직이는) 막대로 대신한다. 상세 텍스트 로그는 접이식으로 유지된다.

## 데모 운용 (확정)

- **상시 데모 = GitHub Pages**: `demo` 브랜치에 `web/` 변경이 push되면 자동 배포
  (`.github/workflows/deploy-pages.yml`) → https://team-t6.github.io/ledger-flow/
- **실서비스 → 데모 자동 동기화**: main에 `web/` 변경이 push되면 demo 브랜치에
  자동 커밋·배포된다 (`.github/workflows/sync-demo.yml`) — 데모를 따로 갱신할 필요 없음
- **데모 샘플 산출물**: `web/demo/result.pdf`·`result.xlsx` (더미 데이터 기반 커밋본) —
  데모 모드의 리포트 열기·장부 다운로드가 이 파일을 쓴다
- **실행 시연 = 로컬 + Cloudflare quick tunnel** (진짜 파이프라인을 보여줄 때):
  1. `python3 orchestrator/server.py` 실행 (포트 8788)
  2. `cloudflared tunnel --url http://localhost:8788` — 출력되는 임시 URL을 참석자에게 공유
  3. 시연이 끝나면 터널 종료 (URL은 사라진다)

## 로컬에서 데모(연출)만 확인

```
python3 -m http.server 8090 --directory web
```

http://localhost:8090 접속. 데모 초대코드는 `LEDGER` (데모 모드 한정 — 실제 모드는 `.env`의 `INVITE_CODE`로 서버 검증).

초대코드 게이트 자체를 끄려면 `index.html` 스크립트 상단의 `INVITE_CODE_ENABLED`를 `false`로 바꾼다 (커밋 대상 설정, 데모·실제 모드 공통 — 끄면 초대코드 입력 없이 바로 이용 가능).
