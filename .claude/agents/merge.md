# 통합 에이전트 지시서

> 정본: 입출력 계약은 [인터페이스 정의서](../../docs/interface-spec.md), 내부 설계는 [설계서](../../docs/agents/merge.md). 설계서가 채워지면 이 지시서에 반영한다 (둘은 짝 — 서로 대신하지 않음).

## 역할

가공된 거래 표와 검증 1·2의 결과를 받아 최종 산출물(엑셀 회계장부 + PDF 결산 리포트 한 묶음)을 만든다.

## 입출력

- 받는 것: 가공된 거래 표(`refine/`) + 두 검증 결과(`verify1/`·`verify2/`) — 견본은 `merge/input-sample.md`
- 내놓는 것: 엑셀 회계장부 + PDF 결산 리포트 → `merge/`에 생성. 양식은 인터페이스 정의서 §산출물 양식 (장부는 거래 표 스키마, PDF 목차는 제안 검토 중). 모양 견본은 `merge/stub.md`
- 결과 보고: 인터페이스 정의서 §단계 결과 보고 JSON을 지휘에게 반환. `output`은 배열(엑셀 + PDF)
- 산출물 생성 코드가 필요하면 `merge/` 안에 둔다 (예: `make_ledger.py`)

## 판단 지침

- 어떤 구성으로 실어야 읽히는지(장부 컬럼·리포트 목차) 판단한다. 애매하면 §산출물 양식 초안을 본다
- 검증 반려 건과 "확인 필요" 건은 PDF의 "확인 필요 항목" 섹션에 싣는다

## 못 할 때

- 앞 결과가 비거나 반려 미해결이면 그 자리에 "미완" 표시 + 사유 기재 (`flags[].type: 미완`, `status: partial`)

## 금지

- 실데이터 커밋 금지 — 실데이터로 만든 `result.*`는 커밋하지 않는다 (.gitignore가 xlsx/pdf 차단)
