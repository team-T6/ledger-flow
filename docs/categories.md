# 카테고리 체계

> 상태: 확정 (확정 로그는 [인터페이스 정의서](interface-spec.md) "다음 단계"). 회사 회계 계정과목을 개인·법인 카드 통합 결산에 맞게 번안한 체계. 가공(분류)·검증 1(적합성 확인)이 공용으로 쓴다.
> (개인카드 카테고리, 법인카드 카테고리) 쌍은 유니크해야 한다 — 같은 쌍의 행을 중복해 두지 않는다. 개인카드 카테고리 하나가 법인카드 카테고리 여럿에 걸리는 것(예: 사용료)은 허용.

## 지출

| 개인카드 카테고리 | 포함 범위 | 법인카드 카테고리 |
|--------------|---|---|
| 식대         | 식사·배달·커피·디저트·편의점 간식 | 복리후생비 |
| 교통비       | 대중교통·택시·주유·주차 | 여비교통비 |
| 여행         | 호텔·항공·출장 경비 | 여비교통비 |
| 차량유지비용 | 정비·세차·통행료 | 차량유지비 |
| 통신비       | 휴대폰·인터넷 | 통신비 |
| 기타물품     | 사무용품·생활용품 | 소모품비 |
| 기타물품     | 가구·가전 | 비품 |
| 구독료       | SaaS·멤버십·콘텐츠 구독 | 지급수수료 |
| 지급수수료   | 금융·플랫폼 수수료, 이자 비용 | 지급수수료·이자비용 |
| 사용료       | 외주 개발·디자인·번역 등 용역 대가 | 외주용역비 |
| 사용료       | 광고 집행·홍보물 제작 | 광고선전비 |
| 경조사비     | 외부 접대·선물·경조금 | 접대비 |
| 교육비       | 강의·서적·세미나 | 교육훈련비·도서인쇄비 |
| 의료비       | 병원·약국 | 복리후생비 |
| 취미생활     | 피트니스·체육관·운동 | 복리후생비 |
| 월세         | 월세 | 임차료 |
| 공과금       | 관리비·전기·가스·수도·세금 | 세금과공과 |
| 보험료       | 사업·차량·보장성 보험 | 보험료 |
| 배송비       | 택배·화물·퀵 | 운반비 |
| 기타         | 위에 속하지 않는 지출 | 잡비 |

## 수익

| 카테고리 | 포함 범위 |
|---|---|
| 입금·매출 | 급여·매출·이체 수입 |
| 환급·캐시백 | 카드 캐시백·환불·환급 |
| 이자·배당 | 이자·배당 수익 |

## 운영 규칙

- 가공 단계에서 분류가 애매한 건은 임의 배정하지 않고 "확인 필요"로 표시한다 (인터페이스 정의서 "못 할 때" 규칙).
- 경조사 구분: 거래처·외부 인사는 접대·경조사(접대비), **임직원 경조사는 회계상 복리후생비**라 구분이 필요하면 비고에 표기한다.
- 카테고리 추가·삭제·이름 변경은 이 문서를 먼저 고치고(spec-first), 가공·검증 1 에이전트가 따른다.
